# 🍔 قالب اختصاصی وردپرس هاشویچ (Hashvich WordPress Theme)

قالب اختصاصی، مدرن و بهینه‌سازی‌شده برای وب‌سایت‌های رستوران و فست‌فود زنجیره‌ای با طراحی راست‌چین (RTL) و تایپوگرافی فارسی **وزیرمتن**.

---

## ✨ ویژگی‌های برجسته
- 🚀 **فوق‌العاده سریع و سبک:** خروجی خالص PHP و CSS بهینه‌سازی‌شده (بدون ابزارهای سنگین بیلد در سمت سرور).
- 🎨 **تایپوگرافی اصیل ایرانی:** میزبانی محلی قلم وزیرمتن در ۵ وزن با فرمت فوق‌سبک WOFF2 (عدم وابستگی به CDN خارجی).
- 🛒 **سازگار با ووکامرس:** آماده برای سیستم سفارش آنلاین غذا، محصولات متغیر (انتخاب اندازه/سایز)، و سبد خرید.
- 🧩 **سازگار با صفحه‌ساز المنتور:** امکان طراحی برگه‌های دلخواه با المنتور در کنار قالب اختصاصی و پشتیبانی از تمپلیت‌های تمام‌عرض.
- 📱 **۱۰۰٪ واکنش‌گرا و طراحی مدرن:** پالت رنگی گرم و هماهنگ برای صنایع غذایی، انیمیشن‌های مینیمال و تجربه کاربری روان (Mobile-First).

---

## 📂 ساختار فایل‌ها
```text
hashvich/
├── style.css             # متادیتای قالب و تعاریف وردپرس
├── functions.php         # ثبت امکانات قالب، ووکامرس، المنتور و استایل‌ها
├── header.php            # هدر اختصاصی و منوی ناوبری
├── footer.php            # فوتر اختصاصی و لینک‌ها
├── index.php             # فال‌بک تمپلیت‌های وردپرس
├── page.php              # تمپلیت برگه وردپرس (سازگار با المنتور)
├── README.md             # مستندات قالب
└── assets/
    ├── css/
    │   ├── fonts.css     # تعاریف فونت‌های محلی وزیرمتن
    │   └── app.css       # استایل رسمی و خالص کامپایل‌شده
    ├── fonts/            # فونت‌های وزیرمتن (WOFF2)
    └── img/
        └── logo.svg      # لوگوی برداری هاشویچ
```

---

## 🛠️ نحوه نصب و راه‌اندازی
1. پوشه `hashvich` را در مسیر `wp-content/themes/` قرار دهید.
2. از پیشخوان وردپرس، بخش **نمایش > پوسته‌ها** رفته و پوسته **Hashvich** را فعال کنید.
3. در صورت نیاز به فروشگاه آنلاین، افزونه **WooCommerce** و در صورت تمایل به طراحی بصری، افزونه **Elementor** را فعال نگه دارید.
